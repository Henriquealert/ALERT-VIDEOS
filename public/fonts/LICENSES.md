# Font licences

All fonts are self-hosted so renders don't depend on network access.
Files are the Latin subsets from Fontsource 5.3.0. Every family is under the
SIL Open Font License 1.1; full text is in `OFL-<family>.txt`.

| File | Family | Brand role |
|---|---|---|
| archivo-latin-800-normal.woff2 | Archivo ExtraBold | Headline, big numerals |
| archivo-narrow-latin-700-italic.woff2 | Archivo Narrow Bold Italic | Statement (act 1 title) |
| instrument-serif-latin-400-italic.woff2 | Instrument Serif Italic | Editorial accent |
| dm-sans-latin-400/500/600-normal.woff2 | DM Sans | Functional: UI text, eyebrow labels |
| dm-mono-latin-500-normal.woff2 | DM Mono | Tag |
| silkscreen-latin-400-normal.woff2 | Silkscreen | Act 2 old-OS dialogs only (on-screen prop, not brand type) |
