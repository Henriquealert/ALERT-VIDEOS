# Brand fonts

Supplied as "Alert Global Tech - Brand Fonts", 21 Oct 2026. These are the only
fonts allowed in any video. Each family folder keeps its `OFL.txt`
(SIL Open Font License 1.1).

| Family | Files loaded (static) | Role |
|---|---|---|
| Archivo Narrow | Regular–Bold, upright and italic | Statement (Bold Italic caps), big numerals |
| DM Sans | Regular–Bold, upright and italic | Headlines, UI text, eyebrows, badges, tags |
| Instrument Serif | Regular, Italic | Editorial accent (italic, one or two words) |

The `variable/` files are kept as supplied but not loaded.
